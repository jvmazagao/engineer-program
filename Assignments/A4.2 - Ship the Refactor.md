# A4.2 — Ship the Refactor

## Why

Analysis without shipping is a well-formatted opinion. The senior move is refactoring feared code in increments so small that production never notices — and proving the pain actually went away.

## Brief

Execute the boundary from A4.1 with safe-refactoring discipline:

- **Small steps, always green.** Every PR mergeable within a day of opening; CI green; characterization tests from A4.1 stay green throughout
- **One intent per PR** — "move X behind interface Y", never "refactor". Aim ≤400 lines of diff
- **Strangler fig or branch-by-abstraction** where the boundary can't flip in one move
- If a PR balloons, split it — don't force it through

**Measure, don't vibe.** Before starting, capture before-metrics; after merging, capture after-metrics over an agreed window (e.g. 6 weeks). Pick 2–3 of: lead time for changes in this module, bug/rollback rate, LOC touched per logical change, time for a newcomer to land a change. State the collection method.

A "no measurable change" result is a valid outcome and must be reported as such — the point is the discipline, and honest measurement is the discipline.

## Tasks

- [ ] Break the refactor into a PR sequence; first PR is the least risky
- [ ] Capture before-metrics with the collection method stated
- [ ] Each PR: single intent, small diff, green CI, linked to the sequence plan
- [ ] Characterization tests green on every PR; no behavior change
- [ ] Split any PR that balloons rather than forcing it
- [ ] Capture after-metrics over the agreed window
- [ ] Write the results note: what improved, what didn't, what you'd do differently

## Acceptance criteria

- [ ] Sequence plan exists with each PR's intent named upfront
- [ ] All PRs merged green; none sat unreviewed more than 2 days
- [ ] Characterization tests from A4.1 stayed green throughout
- [ ] Before/after metrics captured for ≥2 measures, method stated
- [ ] Results note includes at least one honest negative or null result

## Rubric (1–4)

| Criterion | 1 | 2 | 3 | 4 |
|---|---|---|---|---|
| PR discipline | Big-bang merge | Small PRs but long-lived branches | ≤400-line green PRs, fast review cadence | Re-planned the sequence mid-flight when reality disagreed, without drama |
| Safety | Tests broke at some point | Mostly green | Always green | Green *and* de-risked the flip with a flag or abstraction seam |
| Measurement | Feelings only | One metric | 2–3 metrics, method stated | Includes a null/negative result and what it implies |
| Outcome | Shipped, nothing changed | Improvement claimed | Improvement measured | The specific painful change from A4.1 is demonstrably cheap now |
