## Why

"It works on my machine with 100 rows" is how O(n²) code reaches production. After this lab you've *seen* the curve, not just memorized the letters.

## Brief

Write two functions that answer the same question, *"do these two lists share any element?"*:

1. `has_common_naive(a, b)`: nested loops
2. `has_common_fast(a, b)`: using a set

Time both for n = 1 000, 10 000, 50 000, 100 000 (no shared elements, which is the worst case). Plot n vs. time for both on one chart.

## Tasks

- [ ] Create `dsa-from-scratch/00-big-o-lab/` with the two functions and unit tests (empty lists, shared element, no shared element)
- [ ] Benchmark script that prints a table and saves `plot.png`
- [ ] In the submission note, answer:
  - What is the time and space complexity of each function?
  - What happened to the naive version's time when n went ×10? Does it match O(n²)?
  - Name one place in a codebase you work on where this pattern (a lookup inside a loop) could exist

## Acceptance criteria

- [ ] Tests pass
- [ ] Plot shows both curves with labelled axes
- [ ] Complexity stated correctly for time **and** space
- [ ] The ×10 → ~×100 relationship is explained in your own words
- [ ] One real-world example given
